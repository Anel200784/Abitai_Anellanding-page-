Мен туралы

Менің аты-жөнім — Әбітай Анель Өмірсерікқызы. Қазіргі уақытта университетте Ақпараттық жүйелер мамандығы бойынша 2-курс студентімін. IT саласына деген қызығушылығым жоғары және заманауи веб-технологияларды, бағдарламалау тілдерін терең меңгеруге ұмтыламын.

Бос уақытымда жаңа технологияларды зерттеп, әртүрлі IT жобалар жасаумен айналысамын. Кәсіби мақсатым — білікті толық циклды (Full-stack) бағдарламашы атанып, отандық және халықаралық IT жобаларға атсалысу.

Менің дағдыларым

Төменде менің кәсіби дағдыларым мен меңгерген бағыттарым көрсетілген:

  • Бағдарламалау тілдері:
    • Python
    • Java
    • Dart
  • Web-технологиялар:
    • HTML5 & CSS3
    • JavaScript
    • Flask
  1. Дерекқорлармен жұмыс (SQL, SQLite)
  2. Cisco Packet Tracer желілік конфигурациясы
  3. 3ds Max пен 3D модельдеу
  4. Git және GitHub нұсқаларды басқару жүйесі

Менің жетістіктерім

  • Университетшілік программистер олимпиадасына қатысып, белсенділік таныттым.
  • Python және Web-бағыттар бойынша онлайн сертификаттар алдым.
  • Хакатон байқауына қатысып, өз жобамды сәтті қорғадым.
  • «Ақпараттық жүйелер негіздері» тақырыбында оқу курстық жобасын үздік аяқтадым.
  • Ғылыми жоба аясында баяндама жасадым. (15 мамыр 2026 жыл)
